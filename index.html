Neues Rezept

🤖 KI-Import: Rezept-Text einfügen, mehrere Screenshots auswählen oder einen Link einfügen (z. B. Dr. Oetker oder Instagram) – die KI liest es aus und füllt das Formular. Kombinieren ist erlaubt. Danach prüfen und unten speichern.

Gespeichert wird als Datei recipes/<titel>.md nach FORMAT.md direkt auf main. Mit Internet wird sofort committet; offline wird es lokal gepuffert und automatisch später hochgeladen.

📅 Wochenplan

Der Plan wird über das Rezept-Repo (Datei plan/wochenplan.json) mit allen Nutzern synchronisiert, die einen GitHub-Zugang zum Repo haben: Änderungen werden beim Öffnen des Plan-Tabs automatisch hoch- und runtergeladen. „Plan auf die Einkaufsliste“ addiert die Zutaten aller Gerichte der angezeigten Woche. Mit ‹ › zwischen Kalenderwochen blättern, „🤖 Woche planen“ füllt die Woche per KI.

Einstellungen

GitHub-Token: nötig fürs Laden der Rezepte und für neue Rezepte.
Empfohlen: Fine-grained PAT, Zugriff nur auf das Repo Rezepte-, Berechtigung Contents: Read and write.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. „Generate new token“, Repository access: Only select repositories → Rezepte-
  3. Permissions → Contents: Read and write → Generate
